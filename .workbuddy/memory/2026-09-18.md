## Icon R2（向量重繪路線，`icon-lab-2/`）

- 使用者 item-by-item 拍板：向量重繪新一輪／差異軸＝2 閘道 + 2 計量 + 1 混血／交付＝母稿 + 深淺預覽
- 判定 R1 的 ImageGen 概念稿不合規：預切圓角（HIG 明文禁止，會破壞鏡面高光並使邊緣鋸齒）、粒子光暈過多、v5 彩虹色差、v4 綠色撞狀態燈、32px 糊
- 5 版：A1 Fork（一入三出）／A2 Funnel（匯入單出 + 2 道負空間切口）／B1 Quota T（豎筆下段半透明＝配額）／B2 Bars（三柱＝堆疊趨勢）／C1 Split-T（T 豎筆再分兩支＝混血）
- 產出 `D://token counter\icon-lab-2\`，生成器 `gen_icons.py` 可全量重跑：
  `icon-{a1,a2,b1,b2,c1}.svg`（正方形不預切）／`-squircle.svg`（22.7% 圓角顯示變體）／`icon-*-base-1024.png`／`icon-*-squircle-1024.png`／`preview-dark.png`／`preview-light.png`
- Liquid Glass 落地：底色漸層 / 頂部半透明 core / 底部折射厚度 / 頂緣鏡面高光（橫向淡出，非白框）；環境光暈由 5 顆降到 2 顆
- **踩坑（重要）**：
  1. SVG `fill="url(u-fg)"` 漏 `#` → 無聲失效變灰。必須 `url(#u-fg)`（同一錯誤犯了兩次）
  2. 漸層不能掛在「整畫布 rect」上當形狀填色 —— 純描邊幾何（stroke-only path）只會描到畫布邊框。正解：paint 屬性直接掛在幾何本身，再用 mask 裁切
  3. Chrome headless 截圖需獨立 `--user-data-dir`，且 PNG 非同步落地，須輪詢檔案大小連續穩定
  4. 3.12+ 嵌套 f-string 仍易踩雷，先把字串算成變數再進 f-string
